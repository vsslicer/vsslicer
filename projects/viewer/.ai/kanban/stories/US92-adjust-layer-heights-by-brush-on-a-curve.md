title: "Adjust layer heights by brush on a curve"
status: reviewed
epic: VSS:E54
---

As a user, I want to see the layer heights as a curve beside the object and raise or lower them with a brush, so that I control quality where it matters.

## Acceptance criteria

- [ ] A curve of layer height against Z sits beside the object and bands on the object are shaded by layer height
- [ ] Brush, adaptive quality slider, smooth radius and reset work and are one undo step each under the inverse property test
- [ ] Controls are disabled with the reason on a read-only file or a locked plate
- [ ] Verified only on fixtures (D5)

## Out of scope

- Height-range tool (US93)
