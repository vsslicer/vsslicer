id: US96
title: "Scale a model to a measured length"
status: reviewed
epic: VSS:E55
---

As a user, I want to scale an object so that a measured length becomes a value I type, so that I can fit a part to a real dimension.

## Acceptance criteria

- [ ] Scale to this length from a distance or diameter readout, uniform or along one axis, through the existing scale command
- [ ] The scaled object measures the typed length within 0.01 mm
- [ ] Undo restores the transform; disabled on a locked plate or a read-only file
- [ ] Verified only on fixtures (D5)

## Out of scope

- Non-uniform scaling presets
