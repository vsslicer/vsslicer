title: "A user or CI job can verify the signature archive of every published extension version"
status: reviewed
epic: VSS:E68
---

As a release engineer, I want every published version to carry a signature archive made with the registry's key pair, so that `ovsx verify` proves the VSIX matches what we published.

## Acceptance criteria

- [ ] `ovsx.integrity.key-pair` is configured; the development key pair is generated by a script and the production key is read from a secret, never committed
- [ ] Every version published to the local instance has a signature archive and `ovsx verify` passes on it in CI; a tampered VSIX fails verification
- [ ] The key-handling notes say how the key is rotated and where it lives

## Out of scope

- Editor-side signature enforcement (stock VS Code checks only Microsoft signatures, VSCodium disables verification); would be fork code in E69.
