## Progress

Done in `vsslicer/modules/gcode-parser`, published as 0.3.0 (registry left running). Notes: `.reference/notes/GCP-4-roles-layers.md`.

- Tables (`src/domain/tag-tables.ts`): Prusa/Super names (PrusaSlicer@30ef591 libpgcode `Types.hpp:308-319` tags, `ProcessorImpl.cpp:1793-1822` names), Orca/Bambu names (OrcaSlicer@09aa0114 `ExtrusionEntity.cpp:701-742`, `GCodeProcessor.cpp:100-150`), Bambu extras (BambuStudio@79df7ae), Cura (CuraEngine@47b0388). Each has a Copyright line; `check-licence` passes. The clone's Types.hpp:308-319 is libpgcode's, not libvgcode's.
- `src/domain/slicer-tags.ts`: slicer from `; generated by` / `; BambuStudio` / Cura header, flavour from `; gcode_flavor =` / `;FLAVOR:`, roles from `;TYPE:` / `; FEATURE:`, layers from `;LAYER_CHANGE` / `; CHANGE_LAYER` / `;LAYER:` with z from `;Z:` / `; Z_HEIGHT:` (or the first extrusion). Role is written into every move; `Chunk.layers` filled per chunk; `Chunk.slicer` set.
- Flavour precedence: `flavour` option, else detected (from that line on), else marlin. Caveat: PrusaSlicer names its flavour only at end of file, so earlier lines use Marlin units (documented in README).
- No tags: roles Unknown, one `no-slicer-tags` info diagnostic at the end (says what was missing). Unknown role names: `unknown-role` warning once per name.
- Goldens regenerated with `slicer`, `flavour`, `layerCount`, `roleHistogram` via the injectable summariser. Cross-checks in `test/tags.test.ts`: layer count = count of layer-change comments (all 10 files), layer z = stated z values, role histogram = independent line scan, slicer = manifest, flavour = `gcode_flavor` line; Cura via inline samples; chunk-split layers; flavour precedence; detection edge cases.
- Verified: `pnpm lint` (eslint, prettier, tsc), `pnpm test` (151 pass), `pnpm build`, check-licence, publish 0.3.0, empty-store proof (`node_modules` removed, `CI=true npm_config_store_dir=<tmp> pnpm install --frozen-lockfile`, then lint/test/build green).
- Not done: width/height, wipe flag, `;MESH:` names, Cura fixture (Q9).
- Files (repo-relative): `vsslicer/modules/gcode-parser/` `package.json` (0.3.0, tooling ^0.6.0), `pnpm-lock.yaml`, `CHANGELOG.md`, `README.md`, `src/domain/{tag-tables,slicer-tags,chunk-writer,machine,parser}.ts`, `test/tags.test.ts`, `test/support/{parser-summary,run}.ts`, `test/golden/**/*.json`; `.reference/notes/GCP-4-roles-layers.md`.
