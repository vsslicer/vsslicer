As a user, I want to click a face and have the object lie on it, so that a model exported in the wrong orientation prints flat.

## Acceptance criteria

- [ ] Picking a face rotates the object so the face normal points down and drops it to the bed
- [ ] Undo restores the original transform exactly
- [ ] Verified only on fixtures (D5)

## Out of scope

- Auto-orient (E55)
