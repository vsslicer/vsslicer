Compares each part's source slice of the `Project` with the snapshot taken at read time. A part with an unchanged slice is copied as original bytes; a changed slice is regenerated by its writer.

**Code:** `vsslicer/modules/core/3mf/src/application/writer/` (module: `3mf`, layer: `application`)

## Acceptance criteria

- [ ] After an edit to one object, every part not derived from it is byte-identical in the output (per-part compare on all dialect fixtures)
- [ ] A changed part is regenerated and nothing else is
- [ ] Open and save with no edit is byte-identical to the input
- [ ] The decision for each part (copied, regenerated, removed) is returned as data for the save notice
