A user adds a printer in a webview wizard built from the settings-form components, or with the keyboard-driven quick pick, and ends in the settings form with the resolved default process open.

## Acceptance criteria

- [ ] Both drivers reach the same instance (same test, two drivers) for each ecosystem fixture
- [ ] Finishing opens the resolved default process in the form; selected materials and the default process show in the tree
- [ ] Keyboard walk and axe-core pass on the wizard

## Out of scope

- Editing existing instances (E16).
