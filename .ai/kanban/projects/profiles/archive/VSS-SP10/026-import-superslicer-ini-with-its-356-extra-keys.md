SuperSlicer INI uses the Prusa dialect; its extra keys must map through the catalogue or be listed native-only.

**Code:** `vsslicer/modules/profiles-prusa/src/adapters/import/` (module: `profiles-prusa`, layer: `adapters`)

## Acceptance criteria

- [x] A SuperSlicer@1f3d287 fixture bundle imports; each of the 356 extra keys is mapped (with `superslicer.` prefix where needed) or reported native-only
- [x] Entities validate against the schema
- [x] Bounds (rule 25): dialect detection reads a fixed prefix of each file (no scan of the whole input) with a linear-time pattern, key lookup is a set, and the existing per-call caps (bytes, sections, keys, inherited copies) still apply to a SuperSlicer file; hostile cases: the header line past the prefix, a file of thousands of extra keys, a header-only file with no sections
