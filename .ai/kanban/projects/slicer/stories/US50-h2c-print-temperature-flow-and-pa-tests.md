As the owner of an H2C, I want the temperature tower, a flow test and a PA test printed once each, so that the feature is proven on hardware.

## Acceptance criteria

- [ ] One temperature tower, one flow test and one PA test are printed on the H2C through the Calibration command and the send path; firmware version is recorded
- [ ] A value is written back from each result and the diff shown in the preset matches the pick
- [ ] Motion tests are fixtures only (D5)
