# Provenance

The module's own code (the loader in `src/` and the generator in `tools/catalogue/`) is original work written for VSSlicer, under the project licence (see `LICENSE`). Because of the data, the package as a whole is AGPL-3.0-only (Q20, PRF-192); the upstream licence texts are `LICENSE-OrcaSlicer` and `LICENSE-BambuStudio`. The generated catalogue data in `src/data/` is ported from AGPL-3.0 slicers and stays under their terms, set out below. The port is allowed by decision D2.

## Catalogue data

`src/data/*.json` is generated by `tools/catalogue/generate.ts`, which reads the upstream C++ sources as text; nothing upstream is built or run. Do not edit the JSON; regenerate it. Each entry's `provenance` field names the upstream file and line it came from, and each file's `notice` field repeats the licence.
