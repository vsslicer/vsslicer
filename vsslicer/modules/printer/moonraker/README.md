# @vsslicer/printer-moonraker

Printer connector for the Klipper Moonraker API.

Status: scaffold, version 0.0.0. It will implement `printer-api`; that dependency is not declared yet because `printer-api` is unreleased (0.0.0).

Layers (`src/`): `domain`, `application`. Imports point inward only (enforced by `@vsslicer/tooling` lint).
